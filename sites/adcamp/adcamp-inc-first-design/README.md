# AdCamp Inc. — first design (repurposed as a reusable design option)

## Origin

Built as a client pitch for **AdCamp Inc.**, a paving company in Flowood,
Mississippi (source: [`ELSE-Ventures-LLC/adcamp-inc-first-design`](https://github.com/ELSE-Ventures-LLC/adcamp-inc-first-design)).
The client didn't move forward with it. Rather than shelve the work, it's
vendored here as a standalone design option that can be re-skinned for other
clients — same role as an archetype reference template elsewhere in this repo,
just not derived from a `data/leads.json` entry.

## Design system

A dark, glassmorphic "energy/tech" look modeled after t1energy.com: floating
pill navbar with blur, near-black background, soft-white/green accents,
generous whitespace. The full page set (home, services, about, team, FAQs,
contact, terms/privacy, placeholder experience pages) lives under
`app/src/pages/`.

## Structure — why this site differs from the others

Unlike the vanilla-HTML sites elsewhere in `sites/`, this one is a full
Vite + React + TypeScript + Tailwind + shadcn/ui app (originally generated by
Lovable). It's vendored **as-is** under `app/`:

```
app/            the vendored Vite/React project (own package.json, src/, etc.)
public/         BUILD OUTPUT — generated from app/dist by tools/build.mjs, committed
tools/build.mjs npm install + vite build in app/, then syncs app/dist/ → ../public/
wrangler.jsonc  Cloudflare Workers static-assets config, same shape as every other site
```

It still plugs into the standard repo-wide CLI:

```sh
npm run dev    -- adcamp-inc-first-design
npm run build  -- adcamp-inc-first-design
npm run deploy -- adcamp-inc-first-design
```

## Re-skinning this for another client

Treat `app/src` as the design system to inherit: copy this directory to a new
`sites/adcamp/<new-slug>/`, update `wrangler.jsonc`'s `"name"`, and re-skin
copy/branding/imagery in `app/src/pages` and `app/src/components` — the shadcn
component layer, layout, and motion should stay intact.
