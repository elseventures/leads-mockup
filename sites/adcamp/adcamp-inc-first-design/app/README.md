# Adcamp Inc. - First approval

Build a website for a paving company called Adcamp Inc based out of Flowood, Mississippi. 
Only build the hero section and the nav bar right now. use a place holder image. I have attached the reference image for how it looks in the landing page. And how the nav bar looks when i hover over one of the elements.
Only design the desktop view right now. I will provide the layout style for the mobile view later. 

here are some specific about how they achieved the look
DESIGN SYSTEM — T1 Energy (t1energy.com)

LAYOUT & SHAPE

- Navbar: Floating pill-shaped, centered, with glassmorphism

- Border radius (navbar): 9999px (full pill/capsule)

- Border radius (cards/sections): ~16px–24px

- Border radius (buttons): ~8px–12px (slightly rounded, not full pill)

- Overall layout: Full-width sections, generous whitespace

COLOR PALETTE

- Background: Deep black/near-black (#000000 or #0A0A0A)

- Primary text: White (#FFFFFF)

- Secondary text: Light gray (#A0A0A0 / #8A8A8A)

- Accent/highlight: Soft warm white or subtle green tint

- Glass fill: rgba(255, 255, 255, 0.05) to rgba(255, 255, 255, 0.1)

- Glass border: rgba(255, 255, 255, 0.08)

TYPOGRAPHY

- Font family: Likely a geometric sans-serif (similar to Inter, Söhne, or Helvetica Neue)

- Headings: Bold/Semibold, large scale (~48-72px for hero, ~32-40px for sections)

- Body text: Regular weight, ~16-18px, generous line-height (~1.5-1.6)

- Monospaced labels for technical specs (TOPCon, Si₃N₄, etc.)

- Letter-spacing: Slightly tight on headings, normal on body

NAVBAR SPECIFICS

- Position: Fixed, centered horizontally

- Shape: Pill/capsule (border-radius: 9999px)

- Effect: Glassmorphism (backdrop-filter: blur(16px))

- Background: Semi-transparent dark (~rgba(255,255,255,0.05))

- Border: 1px solid rgba(255,255,255,0.08)

- Nav items: Clean text links, no underlines, hover opacity change

- CTA button in nav: Slightly different background, same pill radius

ICONS

- Style: Minimal, line/outline icons (not filled)

- Likely custom SVG or a clean icon set like Phosphor, Lucide, or Heroicons (outline variant)

VISUAL EFFECTS

- Glassmorphism on navbar and some cards

- Subtle gradient overlays on hero/section backgrounds

- Smooth scroll transitions

- Parallax-like image reveals on scroll

- Dark mode only (no light variant)

SPACING

- Section padding: ~120px–160px vertical

- Content max-width: ~1200px centered

- Grid gaps: ~24px–32px

STYLE TAGS (from Mobbin)

- Minimal

- Glass

- Technology category
